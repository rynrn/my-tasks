# 📋 my-tasks — ניהול משימות חיים אישיות

מערכת מבוססת קבצי Markdown לניהול משימות בכל תחומי החיים, עם דשבורד מרכזי ופקודות חכמות לעדכון סטטוס.

## 🗂️ מבנה הפרויקט

```
my-tasks/
├── README.md                       ← המסמך הזה
├── DASHBOARD.md                    ← סיכום כל המשימות החשובות [HIGH]
├── home/tasks.md                   ← בית
├── finance/tasks.md                ← פיננסים
├── investment-apartment/tasks.md   ← דירת השקעה
├── hosting-unit/tasks.md           ← יחידת אירוח
├── family/tasks.md                 ← משפחה
└── couple/tasks.md                 ← זוגיות
```

## 📝 פורמט משימה

```markdown
- [ ] [HIGH] תיאור המשימה
```

**רמות דחיפות:**
- `[HIGH]` — דחוף / חשוב מאוד
- `[MED]` — בינוני
- `[LOW]` — נחמד שיקרה

**סטטוסים (checkbox):**
- `- [ ]` — עדיין לא התחיל
- `- [~]` — בתהליך
- `- [x]` — הסתיים

## 📑 סקשנים בכל קובץ

כל קובץ `tasks.md` מחולק לשלושה חלקים:

1. **🔁 שוטף (חוזר)** — משימות חוזרות (תחזוקה, תשלומים, וכו')
2. **⚡ דחוף / חד פעמי** — משימות נקודתיות שצריך לסגור עכשיו
3. **📌 פרויקטים (ארוך טווח)** — מטרות וייעדים לטווח ארוך

## ⚙️ פקודות זמינות

- **`/next-task`** — מעדכן סטטוס משימה (לא התחיל → בתהליך → הסתיים) ומסנכרן את הדשבורד.
- **`/status`** — מציג את כל המשימות מסודרות לפי רמת דחיפות.

## 🚀 איך להתחיל

1. בחר קטגוריה ופתח את `<category>/tasks.md`.
2. הוסף משימות בפורמט הסטנדרטי.
3. הרץ `/status` כדי לראות תמונה כוללת.
4. הרץ `/next-task` כדי להתקדם במשימה.
