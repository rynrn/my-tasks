# /status — תצוגת משימות לפי דחיפות

מטרה: לספק במהירות צפייה כוללת על כל המשימות הפתוחות במערכת, ממוינות לפי רמת דחיפות.

## תהליך עבודה

0. **pull לפני שמציגים** — הרפו משותף בין כמה מחשבים, עובדים על `main` בלבד. כדי לוודא שהמידע עדכני:
   ```bash
   git pull --rebase origin main
   ```
   אם ה-pull נכשל (למשל יש שינויים לא מקומיטים) — דווח למשתמש והצג את המצב המקומי הנוכחי במקום לעצור לגמרי.

1. **קריאה** — סרוק את כל הקבצים `*/tasks.md` ברפו (home, finance, investment-apartment, hosting-unit, family, couple).
2. **חילוץ** — לכל שורת משימה (שמתחילה ב-`- [`), שלוף:
   - סטטוס (`' '` / `'~'` / `'x'`)
   - רמת דחיפות (`HIGH` / `MED` / `LOW`)
   - תיאור
   - קטגוריה (שם התיקייה)
   - סקשן (שוטף / דחוף / פרויקטים)
3. **סינון** — כברירת מחדל הסתר משימות שהסתיימו (`[x]`). אם המשתמש ביקש "הראה גם הסתיימו" — הצג את כולן.
4. **קיבוץ והצגה** — הצג בפורמט הבא, בעברית, עם אימוג'י לעדיפות:

```
🔴 HIGH (N משימות)
  🏠 home  ⚡ דחוף · [ ] לתאם טכנאי לדוד שמש
  💰 finance  ⚡ דחוף · [~] להגיש החזר מס לשנת 2025
  ...

🟡 MED (N משימות)
  ...

🟢 LOW (N משימות)
  ...
```

5. **סיכום בתחתית** — שורה אחת: סך משימות פתוחות, מתוכן כמה בתהליך, וכמה HIGH פתוחות.

## אופציות שהמשתמש עשוי לבקש

- `/status home` — רק קטגוריה אחת.
- `/status high` — רק רמת דחיפות אחת.
- `/status doing` — רק משימות בתהליך (`[~]`).
- `/status done` — הצג גם הסתיימו.

נתח את הארגומנטים ועצב את הסינון בהתאם.

## כללים

- אימוג'י לקטגוריה: 🏠 home · 💰 finance · 🏢 investment-apartment · 🛏️ hosting-unit · 👨‍👩‍👧 family · 💑 couple.
- אל תקצר תיאורי משימות — הצג בשלמותם.
- אל תשנה קבצים — זו פקודה לקריאה בלבד.
- אם אין משימות בקטגוריה / ברמה מסוימת — אל תציג כותרת ריקה.
- מיון פנימי בתוך כל רמת דחיפות: דחוף → שוטף → פרויקטים.
